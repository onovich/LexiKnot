# LexiKnot

[English](README.md)

把正则表达式双向可视化成无限画布节点图的 TypeScript 工具。

![LexiKnot 封面](docs/cover.png)

## 项目包含什么

- 正则与节点图双向转换。
- 无限画布编辑。
- TypeScript 测试。

## 快速开始

安装依赖并启动本地版本：

```bash
npm install
npm run dev
```

仓库还提供 `npm run build`、`npm run test`、`npm run lint`。

## 仓库结构

- `src/` — 应用与库的源代码。
- `docs/` — 项目文档与设计说明。
- `tests/` — 自动化测试与校验材料。
- `index.html` — Web 入口。
- `package.json` — 包脚本与依赖。
